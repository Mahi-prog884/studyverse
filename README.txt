STUDYVERSE 3D GAME ZONE — PDF EXTRACTION VERSION

1. Extract this ZIP on your phone or computer.
2. Open index.html in Chrome or Edge.
3. Open Note Alchemy → choose a PDF → tap “Extract PDF text”.
4. Extracted text appears in the notes box; tap “Summarise notes” to create a demo summary.
5. Internet is required to load the PDF.js library from CDN. Keep the page open while extracting.
6. This extracts selectable text only. Scanned/image-only PDFs need OCR, which is not included.
7. Summary uses simple browser-side demo logic, not a live AI API. Quiz questions are built-in demo questions.
8. Progress saves locally in the browser when storage is available; there is no cloud sync.
